# AIrplanes slot demo

Frontend-only JFK Winter 2026/27 operations demo. The API Server and Canvas are not used.

## Run and verify

- `pnpm --filter @workspace/airplanes dev` through the managed artifact workflow (supplies `PORT` and `BASE_PATH`).
- `pnpm --filter @workspace/airplanes test` — Node's built-in test runner, no extra test dependency.
- `pnpm --filter @workspace/airplanes typecheck`
- `PORT=5173 BASE_PATH=/ pnpm --filter @workspace/airplanes build`

## Demo

Start as Delta on February 14. Marketplace opens at Delta's listings with a prominent Offer a slot action. Select a Delta-held series, choose a lease-out or swap, then post and match it. The seeded JetBlue-to-Delta rescue remains available as a cross-airline example: switch to B6, open the Critical 07:30 Wednesday departure, compare November 1 and return to February 14. Lease out, post the prefilled listing, and propose the match with Delta's Wednesday 07:00–08:00 request. Switch to DL, open Marketplace → Trades, Accept. Switch to FAA → Approvals, Approve. Return to B6 → Utilization: the hero is Covered by lease at 18/22 (81.8%), with zero Critical series.

The seeded B6 noon and AA 15:00 arrival listings provide the reciprocal swap. Swap holdings change on the day after approval. The 21:30 weekday Lost series has a best case of 85 against 88 required.

## Rules and persistence

`src/domain/rules.ts` contains pure calculations, matching and transition validation. The six entity types are in `types.ts`; seeded full-season underlying outcomes are generated by `seed.ts`. Node tests cover boundaries, prescribed scenarios, matching, execution/rejection, history and persistence.

`store.ts` persists mutable demo state in browser localStorage; `persistence.ts` validates saved data before loading. Reset clears user-created listings, trades and audit events and restores the original default role/date and seed. No network or credentials are required. Browser storage failures are shown explicitly.

Match scores average the two sides for swaps: 100 minus one point per six minutes from the wanted time-window midpoint and five points per mismatched weekday. Direction equality, an inclusive time window, overlapping days and equal terms are hard eligibility checks. P1 three-way listings are retained, but three-way execution is not implemented.

Charts show cumulative credit as a percentage of the full-season total, with actual and projected portions and an 80% threshold. The portfolio utilization card is an occurrence-weighted aggregate for context, not an airline-wide compliance measure.

Extended Winter 2027/28 terms are metadata only. All operations, utilization calculations and execution coverage stop at March 27, 2027.
